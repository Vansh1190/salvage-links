# Web research: blogs, newsletters, forums, surveys (pain points + habit loops)

Fetched: 2026-10-27 (UTC). Method: `webfetch` + `curl` (Chrome UA). Every quote/stat below was copied out of HTML/JSON I actually retrieved this session; raw copies were kept in `/tmp/cora/web/`. "date on page" = date printed on the page itself; "n/a" = no date printed, fetched date applies.

Source types covered: developer surveys (Stack Overflow 2025/2026, State of JS 2024, State of CSS 2024), individual dev blogs, newsletter landing/issue pages (ByteByteGo, JavaScript Weekly, CSS-Tricks newsletter, Smashing email), and Discourse-style forums (discuss.python.org, meta.discourse.org, ziggit.dev, internals.rust-lang.org), plus the lobste.rs front-page listing as a complaint-title sampler. HN was reached but deliberately not used as a row (covered in `hn.md`).
